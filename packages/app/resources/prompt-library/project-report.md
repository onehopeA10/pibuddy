请帮我整理一份项目进展汇报的大纲和内容要点。

背景信息（请把【】里的内容换成实际情况）：
- 项目名称与目标：【例如：官网改版项目，目标 10 月底上线】
- 汇报对象与场合：【例如：双周例会向分管副总汇报，10 分钟】
- 当前整体状态：【正常 / 有风险 / 已延期】
- 本期进展（想到什么写什么）：【罗列最近完成的事】
- 遇到的问题或风险：【例如：供应商交付延迟两周 / 关键岗位缺人（没有可写"无"）】
- 需要上级协调的事：【例如：追加预算 / 协调设计资源（没有可写"无"）】

整理要求：
1. 结构固定为：一页话总结（状态灯 + 一句话结论）→ 本期进展 → 里程碑与计划对比 → 风险与问题 → 需要的支持 → 下期计划；
2. 「一页话总结」放最前面：状态用 绿/黄/红 标明，一句话让领导 30 秒抓住"项目怎么样、要不要他做什么"；
3. 「里程碑与计划对比」用表格：里程碑 | 计划时间 | 实际/预计时间 | 偏差说明——延期要写原因和追赶措施，不粉饰；
4. 「风险与问题」每条按"风险 → 影响 → 已采取措施 → 还需要什么"展开；把"需要上级拍板的"与"仅同步周知的"分开；
5. 「需要的支持」写成具体可执行的请求（要谁、要什么、什么时候要），不要写"希望领导多多支持"；
6. 信息不足的地方标注【需补充：xxx】，不编造进度和数据。

参数占位说明：【】内为需要替换的参数；"当前整体状态"请如实填——汇报的价值在于让问题被看见，而不是让页面好看。
