请帮我把下面这份格式混乱的数据整理成规范的表格。

数据说明（请把【】里的内容换成实际情况）：
- 数据来源与含义：【例如：从微信群里手工汇总的报名表 / 多个部门交上来的 Excel 拼在一起】
- 期望的目标列（顺序即最终列顺序）：【例如：姓名、部门、手机号、报名日期、金额】
- 特殊规则（没有可写"无"）：【例如：日期统一为 YYYY-MM-DD；金额保留两位小数；部门名称统一用全称】

清洗要求：
1. 统一格式：日期、电话、金额、单位、全半角、首尾空格按目标列要求归一；
2. 处理重复：完全相同的行只保留一条；疑似重复（如同名不同电话）不要自行合并，单独列出让我判断；
3. 处理缺失：空值统一标为"（缺）"，不允许编造数据补齐；
4. 处理异常：明显不合理的值（如日期在未来、金额为负、手机号位数不对）保留原值，但在"异常清单"里逐条指出；
5. 输出分三部分：① 清洗后的规范表格（Markdown 表格或 CSV，方便我粘贴回 Excel）；② 改动说明（做了哪些归一，各影响多少行）；③ 异常与疑似重复清单（行号 + 原值 + 问题）。
6. 铁律：只整理不篡改——任何一个数据值都不得凭空修改或补齐，拿不准的一律进异常清单。
