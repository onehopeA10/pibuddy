请帮我写一封中文婉拒邮件。

背景信息（请把【】里的内容换成你的实际情况）：
- 收件人及关系：【例如：合作方王经理，合作过两个项目】
- 对方的请求：【例如：希望我们本周内免费追加一轮设计修改】
- 拒绝的真实原因：【例如：团队排期已满 / 超出合同范围 / 预算不足】
- 是否愿意保留合作可能：【愿意 / 不愿意】
- 可以给出的替代方案（没有可写"无"）：【例如：下月初可以安排 / 可按新报价承接】

写作要求：
1. 先真诚致谢或肯定对方，再说明无法答应，拒绝要明确，不要含糊其辞让对方误以为还有机会；
2. 理由简洁得体，不过度解释、不编造借口，也不透露不该透露的内部信息；
3. 如有替代方案，放在拒绝之后作为建设性收尾；
4. 语气professional 且温和，长度控制在 150～250 字；
5. 给出邮件标题 + 正文，落款留【姓名】占位。

参数占位说明：正文中所有【】括起来的部分都是需要你（用户）替换的参数；如果暂时不确定，可以保留【】原样发送，助手会先按通用情况起草，再向你确认细节。
