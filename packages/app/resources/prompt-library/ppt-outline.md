请帮我设计一份 PPT 的逐页大纲。

背景信息（请把【】里的内容换成实际情况）：
- 汇报主题：【例如：Q3 业务复盘 / 新产品立项建议 / 部门年度预算申请】
- 听众是谁：【例如：总经理办公会 / 客户决策层 / 全体员工】
- 我想达成什么：【例如：让领导批准预算 / 让客户同意进入试用 / 同步信息】
- 时长与页数上限：【例如：15 分钟，不超过 12 页】
- 我手里已有的材料：【例如：销售数据、用户调研结论、竞品对比（没有可写"无"）】

设计要求：
1. 先给出整体叙事线（一句话：这份 PPT 讲的是一个什么故事），结构服务于"我想达成什么"，而不是平铺信息；
2. 逐页输出：页码 | 页标题（写成结论句，如"华东区增速放缓的主因是渠道收缩"，不要"华东区情况"）| 本页 3～5 个要点 | 建议的呈现形式（图表 / 表格 / 大字金句 / 照片）；
3. 关键页（如结论页、要资源页）注明"这一页要让听众记住/同意什么"；
4. 页数分配匹配时长（一般每页 1～1.5 分钟），超出上限时主动砍次要内容并说明砍了什么；
5. 需要数据或案例支撑但我材料里没有的，在对应页标注【需补充：xxx】，汇总成"待补材料清单"；
6. 最后给出 3 条听众最可能提出的尖锐问题和应答思路。

参数占位说明：【】内为需要替换的参数；"听众"与"想达成什么"决定整条叙事线，请务必填写。已有材料可以直接粘贴在本消息后面。
