请从下面的内容里提炼出「关键要点」和「行动项清单」。

背景信息（请把【】里的内容换成实际情况）：
- 内容类型：【例如：项目群聊记录 / 往来邮件串 / 领导的长语音转文字】
- 我的角色：【例如：项目负责人 / 参会成员 / 只是被抄送】

提炼要求：
1. 「关键要点」：5～10 条，每条一句话；结论、共识、重要分歧、风险提示分开标注（【结论】【分歧】【风险】），保留关键数字与日期；
2. 「行动项清单」用表格：事项 | 负责人 | 截止时间 | 来源依据。"来源依据"注明出自哪句话（可简短引用），方便我回查；
3. 没写明负责人或时间的行动项照样列出，相应格标"待定"，并在表格下方汇总"需要主动确认的事项"；
4. 单独列一节「与我有关」：按我的角色，指出哪些事需要我做、哪些截止时间与我有关、哪些风险会砸到我头上；
5. 只提炼明说的内容，不揣测言外之意；确有强烈暗示（如"这事再拖就麻烦了"）可列入要点，但要标注"（原文为暗示，建议确认）"。

原始内容（直接粘贴）：
【粘贴群聊记录 / 邮件串 / 转写文本】

参数占位说明：【】内为需要替换的参数；"我的角色"决定「与我有关」一节的视角，请填写。
