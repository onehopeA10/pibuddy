请帮我对比下面几份文档，输出一张对比表和差异分析。

背景信息（请把【】里的内容换成实际情况）：
- 文档是什么：【例如：三家供应商的报价方案 / 两版合同草稿 / 新旧两版制度】
- 对比目的：【例如：选出性价比最高的一家 / 找出新版改了哪些条款】
- 我关心的维度（写"由你定"则由助手先提维度再对比）：【例如：总价、付款方式、交付周期、违约责任、售后】

对比要求：
1. 先用一两句话概括每份文档"是什么、立场是什么"；
2. 对比表：行为维度，列为各文档；同一维度下用可比的口径填写（单位统一、含税口径注明），某文档未提及的维度标"未提及"，绝不脑补；
3. 差异分析：逐条指出实质性差异，并区分"表述不同但意思相同"与"实质条款不同"；对比合同 / 制度类文档时，重点标出对我方不利的差异；
4. 如果对比目的是做选择：按我关心的维度给出倾向性建议 + 理由，同时明确指出"选它要接受的代价"和"还需要向对方确认的问题清单"；
5. 数字、条款编号必须与原文一致；引用关键条款时注明出自哪份文档。

各份文档内容（逐份粘贴，标明名称；或告诉助手读取工作文件夹里的哪些文件）：
【文档一名称】：【粘贴内容或写明文件名】
【文档二名称】：【粘贴内容或写明文件名】
【文档三名称（没有可删除此行）】：【粘贴内容或写明文件名】

参数占位说明：【】内为需要替换的参数；对比维度是这个模板的关键，不确定就写"由你定"，助手会先列维度清单供你挑选。
