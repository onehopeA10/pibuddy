请帮我对下面的明细数据做分组汇总（相当于 Excel 数据透视表），并先跟我确认统计口径。

汇总需求（请把【】里的内容换成实际情况）：
- 数据含义：【例如：全年销售明细，一行一笔订单】
- 分组维度（行）：【例如：按月份 + 大区】
- 汇总指标（值）：【例如：销售额求和、订单数计数、客单价（销售额/订单数）】
- 筛选条件（没有可写"无"）：【例如：只看已回款订单，剔除内部测试单】

执行要求：
1. 动手前先复述你理解的统计口径，逐条确认：每个指标怎么算、含不含税、退款单算不算、空值和重复行怎么处理、时间按下单日还是回款日归属——列成"口径确认清单"，等我确认或直接给出你的默认口径并注明；
2. 汇总表用 Markdown 表格输出，行为分组维度，列为汇总指标，末行给合计；
3. 派生指标（如客单价、占比、环比）注明计算公式；除法遇到分母为 0 时标"—"，不要输出错误值；
4. 表格之后用 3～5 句话点出最值得注意的数字（最高/最低/异常波动），只陈述数据事实，不做主观归因；
5. 如果数据里有影响口径的问题（重复、缺失、单位不一致），先在"数据问题"一节说明这些行是怎么处理的。
