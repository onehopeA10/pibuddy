请根据我的数据和表达目的，推荐合适的图表方案。

背景信息（请把【】里的内容换成实际情况）：
- 数据长什么样：【例如：12 个月 × 4 个产品线的销售额 / 一次问卷的 8 个选项占比】
- 我想让读者一眼看出什么：【例如：A 产品线增速远超其他 / 两个方案的成本差异】
- 展示场合：【例如：给领导的周报 PPT / 印刷版年度报告 / 内部数据看板】
- 制作工具：【例如：Excel / WPS / PowerPoint，写"不限"则按 Excel 给操作建议】

建议要求：
1. 给出首选图表类型 + 一个备选，各用一两句话说明"为什么这种图最能支撑我要表达的结论"；
2. 明确不推荐的类型也点一下（如：类别超过 5 个别用饼图、双 Y 轴容易误导），说明理由；
3. 给出具体配置要点：横纵轴取什么、是否从零起、排序方式、要不要数据标签、颜色怎么用（强调色只给要突出的那一个系列）、标题怎么写成结论句（如"A 线增速领先"而非"销售额统计图"）；
4. 按我的制作工具给出落地步骤（选中哪些列、插入什么图、改哪几处默认设置）；
5. 如果我的数据本身撑不起想表达的结论（如样本太少、口径不一致），请直说，不要硬配图。

数据（可粘贴数据本身，或只描述结构）：
【粘贴数据或描述数据结构】

参数占位说明：【】内为需要替换的参数；"想让读者一眼看出什么"决定图表选型，请务必填写。
