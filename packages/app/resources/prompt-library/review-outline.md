请帮我搭一份个人述职报告的框架，并指导我往里填内容。

背景信息（请把【】里的内容换成实际情况）：
- 述职场合与周期：【例如：年度述职 / 转正答辩 / 晋升答辩，面向部门总监】
- 我的岗位与主要职责：【例如：市场部活动策划，负责线下活动与渠道合作】
- 本周期主要做了什么（想到什么写什么，不用组织语言）：【罗列你的工作内容】
- 有没有量化数据：【例如：办了 8 场活动、获客 1200 人、成本降了 15%（没有可写"暂无"）】
- 下一周期的打算：【简单罗列（没想好可写"帮我建议"）】

框架要求：
1. 结构固定为：开场定位（我的角色一句话）→ 关键成果（2～4 件大事）→ 反思与不足 → 下一周期规划 → 需要的支持；
2. 「关键成果」逐条按 STAR 打磨：背景 → 我做了什么 → 结果（必须落到数字或可验证的事实）；从我罗列的工作里挑最有分量的，并说明为什么挑这几件、其余的怎么一句话带过；
3. 我给的数据不够支撑结论时，标注【需补数据：xxx】告诉我去找什么数字，绝不编造；
4. 「反思与不足」要真诚但有策略：选"已经在改进、且不动摇岗位胜任度"的点，附改进动作；
5. 「下一周期规划」与成果和不足呼应，目标可衡量；
6. 语言口吻是"我向上级汇报"，自信、具体、不堆形容词；每一节给出可直接套用的表述示例。

参数占位说明：【】内为需要替换的参数；工作内容罗列得越全，框架挑重点越准——先全倒出来，取舍交给助手。
