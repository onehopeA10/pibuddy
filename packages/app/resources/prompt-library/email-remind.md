请帮我写一封中文催办（跟进）邮件。

背景信息（请把【】里的内容换成你的实际情况）：
- 收件人及关系：【例如：财务部李老师 / 供应商张工，平级协作】
- 催办的事项：【例如：三月差旅报销单审批 / 合同盖章回传】
- 上次沟通时间与方式：【例如：上周三邮件已发材料，至今未回复】
- 这是第几次催办：【第 1 次 / 第 2 次 / 多次】
- 期望的完成时间：【例如：本周五下班前】
- 拖延会造成的影响：【例如：影响月底结账 / 项目无法按期启动】

写作要求：
1. 开头先简要回顾事项与此前的沟通，让对方无需翻记录就能对上号；
2. 明确说出期望的完成时间，以及到期未完成的客观影响（陈述事实，不指责、不施压过度）；
3. 主动询问对方是否遇到困难、是否需要我方补充材料——把催办包装成协作；
4. 第 1 次催办语气轻，第 2 次以上可适度加重并抄送说明（如需抄送请注明【抄送对象】）；
5. 给出邮件标题 + 正文，标题里带上事项关键词和"跟进/提醒"字样，落款留【姓名】。

参数占位说明：【】内为需要替换的参数；「这是第几次催办」会直接影响语气轻重，请如实填写。
