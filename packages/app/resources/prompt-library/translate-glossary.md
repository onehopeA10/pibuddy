背景信息（请把【】里的内容换成实际情况）：
- 翻译方向：【中译英 / 英译中】
- 文档类型：【例如：产品手册 / 合同条款 / 技术规格书】
- 术语表（左边原文、右边必须使用的译法，一行一条）：
【示例——
  验收：acceptance
  甲方：Party A
  交付物：deliverables
（把示例整体替换成你的术语表）】

翻译要求：
1. 术语表是硬约束：凡在表内的词，译文必须逐处使用指定译法，即使你认为有更好的译法也不得替换；同一术语在全文中的译法必须一处不差地一致；
2. 术语表没覆盖、但在文中反复出现的关键名词，由你先选定一个译法并全程统一，在输出末尾的"新增术语建议"里列出（原文 | 你采用的译法 | 备选译法），供我并入术语表；
3. 如果术语表内部有冲突（同一词两种译法）或某条译法在具体语境里明显不通，不要擅自改动：按术语表执行，并在"术语问题"里说明；
4. 正文翻译遵循文档类型的文体（合同用严谨法律语体、手册用简明指令语体）；
5. 输出：译文全文 → 新增术语建议 → 术语问题（没有则写"无"）。
