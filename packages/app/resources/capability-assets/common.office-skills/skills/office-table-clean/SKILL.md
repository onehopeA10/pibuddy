# 表格数据处理

帮办公用户处理表格：去重、筛选、汇总。用户口中的「表格」九成是 Excel 或 CSV；你的工作是先把口径问清楚，再安全地算出结果。

## 与用户配合的步骤化流程

1. **认表**：确认文件格式。
   - `.csv`：直接进入第 2 步。
   - `.xlsx` / `.xls`：先转 CSV，见下方「Excel 怎么办」。
2. **预览并复述**：读表头 + 前 5 行，用一句话向用户复述你的理解（「这张表有 8 列、约 1200 行，每行是一个客户」），并确认关键口径：
   - 去重：**哪一列（或哪几列组合）算同一条**？重复时保留第一条还是最后一条？
   - 筛选：条件是等于、包含还是数值比较？
   - 汇总：按哪列分组，数行数还是对哪列求和？
3. **处理**：优先用本技能自带的零依赖脚本（见下），大表也不怕；脚本不可用时的降级见「没有 Node 怎么办」。
4. **交付**：结果写成**新文件**（如 `客户-去重结果.csv`），报告处理前后行数（「1200 行 → 987 行，去掉 213 条重复」），并抽 2-3 行结果让用户瞄一眼对不对。

## 自带脚本 csv-tool.mjs

与本 SKILL.md 同目录的 `scripts/csv-tool.mjs`（零依赖，`node --version` 能出版本号就能跑；从技能加载路径定位它的绝对路径）：

```bash
# 预览：表头、行数、前 N 行
node scripts/csv-tool.mjs preview 客户.csv --rows 5

# 去重：按一列或多列（逗号分隔）为键，保留首条
node scripts/csv-tool.mjs dedupe 客户.csv --key 手机号 --out 客户-去重.csv

# 筛选：--where 精确等于，--contains 包含（可多个，全部满足才保留）
node scripts/csv-tool.mjs filter 客户.csv --where 城市=北京 --contains 备注:VIP --out 北京VIP.csv

# 透视汇总：按列分组，数行数和/或对数值列求和
node scripts/csv-tool.mjs pivot 客户.csv --group 城市 --count --sum 金额 --out 城市汇总.csv
```

脚本已处理好两个最容易翻车的点：**带引号/逗号/换行的单元格**（标准 CSV 引号规则）与**中文编码**（自动识别 UTF-8 BOM，输出带 BOM 的 UTF-8，Excel 双击打开不乱码）。输出文件已存在时自动加序号，不覆盖。

## Excel（xlsx）怎么办

本技能不携带 xlsx 解析库，两条转换路（如实告诉用户）：

1. **让用户动手（最稳）**：Excel 打开 → 文件 → 另存为 → 「CSV UTF-8（逗号分隔）(*.csv)」。多个工作表要各存一份，提醒用户 CSV 只保留当前工作表、不保留公式和格式（保留的是公式算出的值）。
2. **装了 Excel 的 Windows 上自动转**：用 PowerShell 驱动 Excel（COM）转换，见 [references/xlsx-to-csv.md](references/xlsx-to-csv.md)。跑之前告诉用户「我要调用你机器上的 Excel 来转换」。没装 Excel 时此路不通，退回第 1 条。

处理结果要「转回 Excel」时：交付 CSV 即可（Excel 直接打开）；用户坚持要 .xlsx 时如实说明需要用 Excel 打开 CSV 后另存为 xlsx。

## 没有 Node 怎么办

`node --version` 报错说明用户机器没有 Node。此时：

- **小表（约 2000 行以内）**：你直接读文件自己处理（注意 CSV 引号规则：含逗号/引号/换行的单元格外层有双引号、内部双引号成对转义），结果同样写新文件。
- **大表**：如实告诉用户这台机器缺少处理大表的运行环境，给出选项（装 Node / 缩小数据范围 / 转用 Excel 自带的「删除重复项」「数据透视表」功能并给出点按路径）。

## 铁律

- 原表**只读**：一切结果写新文件，文件名说明用途（`-去重`、`-筛选`、`-汇总`）。
- 口径先确认再动手：去重键没确认之前不去重——按错列去重等于替用户删数据。
- 行数变化必须报告：处理前多少行、处理后多少行、差在哪。
