# 文件批量整理

把一批杂乱的文件按规则归类、重命名。服务对象是非程序员办公用户：他们描述的是意图（「把下载文件夹里的图片按月份归档」），你负责把意图折成安全、可预览、可撤回的具体操作。

## 安全操作规程（不可跳过、不可调换顺序）

1. **先看清楚**：只读扫描目标文件夹（必要时递归），统计文件数、类型分布、时间范围。超过 500 个文件时先告知规模，问用户是否缩小范围。
2. **列清单预览**：把将要发生的每一条变化列成对照表（Markdown 表格）给用户看：

   | 现在的文件 | 将变成 | 动作 |
   |---|---|---|
   | 下载/IMG_2031.jpg | 图片/2026-05/IMG_2031.jpg | 移动 |
   | 下载/报告(1).docx | 文档/报告-02.docx | 移动+重命名 |

   条目太多时按规则分组展示（每组给 3-5 个示例 + 总数），并明确说「还有 N 个同规则文件」。
3. **等用户确认**：明确问「确认按这份清单执行吗？」。用户没有明确说「确认 / 执行 / 好」之前，一个文件都不许动。用户要求调整规则时，回到第 2 步重新出清单。
4. **执行**：逐条移动 / 重命名。执行完输出结果摘要：成功 N 条、跳过 N 条（附原因）。

## 铁律

- **绝不静默覆盖**：目标位置已有同名文件时，不覆盖、不询问逐个处理，而是自动给新文件追加序号（`报告.docx` → `报告-2.docx`、`报告-3.docx`），并在结果摘要里标出这些条目。
- **绝不删除**：本技能只移动和重命名。用户要求「清理 / 删掉重复的」时，把候选列成清单并建议用户自己确认删除，或把它们移进一个 `_待删除/` 子文件夹，由用户最终处置。
- **范围收容**：只操作用户指定的文件夹。规则再合理，也不去动范围外的任何文件。
- **可回溯**：执行前把最终确认的对照清单原样保存一份为目标文件夹下的 `整理记录-<日期>.md`，用户日后想找回某个文件时有账可查。

## 常用归类规则

- **按日期**：优先用文件名里的日期（`20260503`、`2026-05-03`、`2026年5月`），文件名没有时用文件的修改时间。归档目录形如 `2026-05/`。
- **按类型**：图片（jpg/png/gif/webp/heic）、文档（doc/docx/pdf/txt/md）、表格（xls/xlsx/csv）、演示（ppt/pptx）、压缩包（zip/rar/7z）、安装包（exe/msi/dmg）、其它。
- **按关键词**：用户给的关键词命中文件名即归入对应文件夹；一个文件命中多个关键词时归入第一个命中的，并在清单里标注。
- **统一命名**：常见诉求是「项目名-日期-序号.扩展名」。序号补零对齐（01、02…），排序才不会乱。
