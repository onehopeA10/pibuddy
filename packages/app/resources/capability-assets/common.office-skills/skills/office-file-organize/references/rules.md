# 文件整理细则

SKILL.md 的补充细节。规程与铁律以 SKILL.md 为准。

## 重命名的合法性

- Windows 文件名不能含 `\ / : * ? " < > |`，且不能以空格或点结尾；从用户输入或
  文档标题生成文件名时把这些字符替换成 `-`。
- 保留原扩展名，绝不因为重命名改掉扩展名（`报告.docx` 改成 `报告.pdf` 不是重命名，
  是谎报格式）。
- 大小写不同视为重名（Windows / macOS 默认文件系统不区分大小写），追加序号处理。

## 追加序号的规则

目标已存在 `名字.扩展名` 时，依次尝试 `名字-2.扩展名`、`名字-3.扩展名`…直到不冲突。
统一命名场景下序号补零对齐（`-02`、`-03`），与既有清单宽度一致。

## 跳过而不是硬来

以下情况把文件列入「跳过」并给出原因，不要中断整批任务：

- 文件被占用（Office 正开着它）——提示用户关掉后可再跑一次；
- 没有权限；
- 隐藏文件 / 系统文件（以 `.` 开头、`desktop.ini`、`Thumbs.db`、`.DS_Store`）——
  默认不动它们，除非用户点名；
- 快捷方式（.lnk）——移动它通常会失效，默认跳过并说明。

## 日期解析优先级

1. 文件名中的完整日期：`2026-05-03`、`20260503`、`2026年5月3日`；
2. 文件名中的年月：`2026-05`、`2026年5月`；
3. 文件系统的修改时间（在清单里标注「按修改时间」，因为它可能不是内容的真实日期，
   比如从别处拷贝过来的文件）。

## 大批量的清单展示

超过 50 条时按规则分组：每组展示前 3-5 条 + 「…还有 N 个同规则文件」。
用户要求看全量时，把完整清单写成目标文件夹下的 `整理预览-<日期>.md` 让用户打开看。
