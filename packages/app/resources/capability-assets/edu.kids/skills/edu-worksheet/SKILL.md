# 练习卷生成（edu-worksheet）

给家长生成一份**答案保证正确**、可直接打印的小学数学练习卷。

## 铁律

- 题目和标准答案**只能来自 `edu.kids.math_worksheet` 工具的返回**。不要自己编题，不要心算、修改或"修正"工具给出的任何答案——答案正确性由代码自校验保证，你的工作只是排版。
- 工具返回里带 `adjusted` 说明时（请求的运算超出该年级教学范围被调整），要把这句话原样转告家长。

## 步骤

1. **定参数**。四个参数：`grade`(1-6)、`operation`(add/sub/mul/div/mix)、`count`(1-50，默认 20)、`difficulty`(basic/challenge，默认 basic)。年级从对话或孩子档案推断；推断不出**先问家长一句**，不要瞎猜。
2. **调工具** `edu.kids.math_worksheet`，得到 JSON：`problems[]`（index/text/answer）与 `seed`。
3. **排版**成一个 markdown 文件：
   - 卷头：标题（如「三年级乘法练习卷（基础）」）、日期、姓名/用时填空线、共几题。
   - 题目区：按题号排，**每行两题**（用表格或对齐空格），每题后留答题横线；不出现任何答案。
   - 分隔：题目区结束后用 `\n---\n` 分页，再写「答案页（家长保管）」。
   - 答案页：紧凑排版（一行多题），末尾附一行小字：`seed: <seed>`（凭它可复现同一份卷）。
4. **保存**到 `edu-kids/worksheets/YYYY-MM-DD-<运算中文名>-<题量>题.md`（目录不存在先创建）。家长明确要求"答案单独一份"时才拆成两个文件。
5. **汇报**：告诉家长文件路径 + 一句话摘要（年级/运算/题量/难度），不要把整卷贴在对话里。

## 与错题本联动

如果这次出卷是错题复习的后续（对话里提到过薄弱知识点），在卷头加一行「本卷针对：<知识点>」，并把 operation 选成对应运算。
