# 错题本（edu-mistake-book）

三个动作：**记错题**、**分析薄弱点**、**出复习卷**。数据文件是唯一真相源。

## 数据文件约定（必须严格遵守）

- 文件：工作区相对路径 `edu-kids/mistakes.jsonl`（目录不存在先创建）。
- 格式：UTF-8，**每行一个 JSON 对象，只追加，绝不改写或删除历史行**。
- 字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `date` | 是 | `YYYY-MM-DD`（记录当天） |
| `subject` | 是 | `english` / `math` / `chinese` / `science` 之一 |
| `topic` | 是 | 知识点短语（聚类键），如「三位数退位减法」「there be 句型」 |
| `question` | 是 | 原题（长题可截断到能认出是哪道题） |
| `grade` | 否 | 年级 1-6 |
| `wrong` | 否 | 孩子的错误答案 |
| `right` | 否 | 正确答案 |
| `note` | 否 | 错因一句话，如「忘了借位」 |

- 示例行：`{"date":"2026-08-04","subject":"math","grade":3,"topic":"三位数退位减法","question":"502-178=","wrong":"336","right":"324","note":"忘了借位"}`
- **topic 用规范短语**：同类错题必须用同一个 topic（先读一遍文件里已有的 topic，能归入已有的就复用，不要造近义新词——聚类全靠它）。
- 读文件时遇到坏行**跳过并继续**，不要因一行坏数据拒绝整个文件。PiBuddy 的学习面板按同一约定读取展示，别的字段名它不认识。

## 动作一：记错题

从家长的描述里提取字段（缺 topic 时自己归纳一个规范短语；缺 right 时先算出正确答案）→ 追加一行 → 用一句话复述记了什么（「已记入错题本：数学·三位数退位减法」）。一次可以记多道，每道一行。

## 动作二：分析薄弱点

读整个文件 → 按 subject 分组、组内按 topic 聚类计数 → 报告：错题最多的 2-3 个知识点（附各自出现次数与最近日期）、是否有最近两周新增集中的点。**表述必须是建设性的**：说「退位减法的借位还需要多练几次」，不说「老是错」。

## 动作三：出复习卷

1. 选定目标知识点（家长指定，或取动作二里最薄弱的）。
2. 出题：
   - **数学计算类** topic：调用 `edu.kids.math_worksheet` 工具出同类新题（grade 取错题里的 grade，operation 对应知识点，10-20 题），题目与答案以工具返回为准，不自己编。
   - 其它（概念题 / 语文 / 英语）：基于原错题改编 5-10 道**变式题**（换数字、换情境、考同一个点），自己给出标准答案并逐题复核一遍。
3. 排版：与 edu-worksheet 相同的可打印规范（卷头 + 每行两题 + `---` 分页 + 答案页），卷头标注「本卷针对：<知识点>」。
4. 保存到 `edu-kids/reviews/YYYY-MM-DD-复习卷-<知识点>.md`，汇报路径与摘要。

## 语气

错题本是帮孩子进步的工具，不是批评记录。所有面向家长/孩子的输出都用鼓励式表达。
