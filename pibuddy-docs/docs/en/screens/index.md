# Screens

These frames come from the `.tmp-*.png` working screenshots at the repository root. They are curated into the docs so you can see the product, not so they can replace a spec.

In that batch, `acc / lib / mem / tasks / term / v4` are byte-identical; only one frame is kept as “session list + empty workspace”. `v2` is a developer terminal, not the product UI, and is omitted. `p-acc` and `p-set` duplicate the tool-flow frame and are omitted.
